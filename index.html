Jew Code

A short, structured way to describe your relationship to Jewish identity, practice and culture, defined by DEP-0248. These pages help you write one and read other people's.

-----BEGIN JEW CODE BLOCK-----
Version: 1.0

Bj O+ K+ Sh+ Ho- Pr+ He:Mo+ Tx+
Lg:HeYi Cm+ Cu++ Rl+ G+ Il+ Z?

-----END JEW CODE BLOCK-----
Create Answer a series of questions and your block is built as you go. Skip anything you'd rather not say. Decode Paste a block to read it in plain English. You can also open it in Create to edit it.

Everything runs in your browser. Your answers aren't sent anywhere. Share links keep them in the part of the URL after #, which browsers don't send to the server.

A browser port of omer's jewcodegen (Apache-2.0). Per the spec, a block is self-reported and subjective. It isn't proof of anything.
